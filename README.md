# お風呂ルーレット

お風呂ルーレットは、
お風呂に入らなければならないプレッシャーを和らげ、
ルーレットで気軽に決めるWebアプリです。

## 概要

疲れていてお風呂に入る気力が出ないときに、
やることをルーレットに任せ、身体が重い原因を天気のせいにして気持ちを楽にするきっかけを作ります。

一覧から「シャワーのみ」「30%お風呂」などの選択肢が選ばれ、納得がいくまで何度でも回し直せます。
また、現在地の天気や気圧を表示し、調子が出ない理由が環境にあることを示します。

利用のプレッシャーにならないよう、過去の履歴は一切保存しません。

## 主な機能

* **ルーレットでやることを決定**: 一覧の中から今日のお風呂メニューをランダムに選びます。
* **何度でも回し直せる**: 気分に合わない結果が出ても、気にせず引き直せます。
* **やる気が出ない理由を表示**: 現在地の天気や気圧から、身体が重くなりやすい状況を伝えます。
* **履歴を残さない設計**: 回数や記録を保存しないため、日々の義務感なく利用できます。

## 技術構成

* TypeScript
* Vite
* HTML5 / CSS3
* 気象庁防災情報XMLフォーマット 定時Atomフィード

## セットアップ手順

```bash

cd BathRoulette
npm install
```

### 開発用サーバー起動

```bash
npm run dev
```

### プロダクションビルド

```bash
npm run build

```

## 外部データの出典および加工に関する明示

本アプリケーションでは、現在地の判別および環境要因の生成にあたり、
以下のオープンデータを取得および加工して利用しています。

### 1. 気象庁データ

* **原データ**: 「気象庁防災情報XMLフォーマット」気象庁（ https://www.data.jma.go.jp/developer/xml/feed/regular.xml ）
* **加工利用の表示**: 「気象庁防災情報XMLフォーマット」気象庁をもとに ShinH 作成。
* **編集内容と責任**: 気象庁が公開する定時フィードおよび府県天気予報電文を取得し、現在地の都道府県に応じた天候概況を抽出した上で、日常的な解説テキストおよびアイコンへ独自に変換して表示しています。元の電文に対する編集責任は開発者 ShinH（ https://github.com/Shinh0707 ）に帰属します。気象業務法第17条に基づく独自の気象予報業務を行うものではありません。


### 2. 国土地理院データ

* **原データ**: 「簡易逆ジオコーディングサービス」国土地理院（ https://mreversegeocoder.gsi.go.jp/reverse-geocoder/LonLatToAddress ）
* **加工利用の表示**: 「簡易逆ジオコーディングサービス」国土地理院をもとに ShinH 作成。
* **編集内容**: 端末から取得したGPS座標をもとに自治体コードを取得し、都道府県単位の判別に利用しています。本アプリケーションの結果は国土地理院が直接作成・公表したものではありません。
